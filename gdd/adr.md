## 2026-10-06 SG8 plugin の言語

- 何を決めたか：plugin のどこまでを英語にするか（人間の指示「基本的に英語で plugin を作る」の範囲）
- 出した案：
  - A 配るものを全部英語にする：統一される。雛形も英語なので、日本語で使いたい人には合わない
  - B 説明文と README だけ英語：変更は小さい。skill の中身が読めない人には使いにくい
  - C 全部英語にし、報告や質問は使う人の言語で出す：誰でも使えて日本語でも返る。翻訳の量が一番多い
- 選んだ案：C
- 理由：誰でも使えるようにしたい

## 2026-10-07 公開前：ライセンス

- 何を決めたか：公開するときのライセンス
- 出した案：
  - MIT：自由に使え、表示を残すだけ。特許の取り決めはない
  - Apache-2.0：特許の扱いが明記される。改変したファイルに変更を書く条件が増える
  - まだ付けない：見られるが法的には使えず、「誰でも使える」ゴールと合わない
- 選んだ案：MIT
- 理由：誰でも気軽に使えるようにしたい
