# 2026-10-06 SG8 エンジンの置き場所

- 何を決めたか：plugin にするとき、エンジン（gdd-init / gdd-loop の skill、雛形、hook）をリポジトリのどこに置くか
- 出した案：
  - A リポジトリの直下をそのまま plugin にする：一番単純。polaris 自身の gdd/ や docs/ も配られる
  - B plugins/polaris/ に移す：エンジンだけが配られる。polaris の開発は --plugin-dir で起動する
  - C .claude/ に残し、配る用にコピーする：開発のしかたは今のまま。エンジンが2か所になる
- 選んだ案：B
- 理由：配るものだけを配りたい
