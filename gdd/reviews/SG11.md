## 一番自信がない判断

- evaluator を plugin の `agents/` に置き、`subagent_type: "polaris:evaluator"` で呼ぶ形にした。公式ドキュメントでは plugin の agents/ は自動で見つかり `<plugin>:<agent>` で指す、とあるが、skill の中から Agent ツールでこの名前が解決されることは起動確認で初めて分かる

## 捨てた案

- evaluator の指示を SKILL.md 手順5に直接書く：SKILL.md が長くなる。Claude Code が plugin のサブエージェント定義を標準で持てるのでそちらに置いた
- evaluator に Bash を渡さない：定量基準（コマンドの出力、テスト）を自分で測れなくなる
