# サブゴールレビュー：SG18 plugin の全挙動を eval で確かめられるようにする

## 何が出来たか、どう触るか

- `plugins/polaris/evals/` を6ケースから15ケースに。人間の答えが要る動きは `context.history_file`（本物のセッション記録と同じ構造の .jsonl。sessionId / uuid / parentUuid 付き）で「AI が質問した」履歴を仕込み、prompt を人間の答えにする
- 人間の実走で15ケース pass（2026-10-08〜09）。途中で落ちた4つは、テスト側3件（グレーダーの `min`/`max`、質問文の正規表現、曖昧なコメント）と history の書式1件で、plugin 側の抜けは無かった
- 走らせ方は README の「Testing the skills」のまま（全件 1.5〜2.5 ドル、`-j 2` で 10 分前後）
